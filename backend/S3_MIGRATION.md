# Миграция на S3 хранилище

## Что изменилось

Теперь все загружаемые файлы (изображения и видео) хранятся в S3-совместимом хранилище (reg.ru), а не локально на сервере.

### Преимущества:
- ✅ Надежное хранение файлов
- ✅ Масштабируемость
- ✅ CDN для быстрой загрузки
- ✅ Не зависит от состояния сервера

## Настройка

### 1. Переменные окружения

В файл `.env` добавлены следующие переменные:

```env
S3_ENDPOINT=https://s3.regru.cloud
S3_BUCKET=etosema
S3_ACCESS_KEY=9CLHOKRTGS2H34LWR3KH
S3_SECRET_KEY=Aytx0TweAKCmKGdWUFlnq4BQNEjYDWsINKKQgffq
S3_REGION=us-east-1
S3_PUBLIC_URL=https://etosema.s3.regru.cloud
```

### 2. Миграция существующих файлов

Если у вас есть локальные файлы в папке `public/uploads/`, их нужно мигрировать на S3:

```bash
npm run migrate:s3
```

Этот скрипт:
1. Найдет все файлы, на которые есть ссылки в базе данных
2. Загрузит их на S3
3. Обновит URL в базе данных

### 3. Запуск сервера

После миграции просто запустите сервер как обычно:

```bash
npm run dev
```

## Как это работает

### Загрузка новых файлов

При загрузке файла через админ-панель:

1. Файл загружается в память (не на диск)
2. Сразу отправляется на S3
3. Возвращается полный публичный URL: `https://etosema.s3.regru.cloud/medias/1234567890-123456789.png`
4. Этот URL сохраняется в базе данных

### API endpoint

**POST** `/api/admin/upload`

- Multipart form-data с полем `file`
- Возвращает полный S3 URL файла
- Поддерживает: JPEG, PNG, GIF, WebP, MP4, WebM
- Максимальный размер: 50 МБ

Пример ответа:
```json
{
  "success": true,
  "data": {
    "url": "https://etosema.s3.regru.cloud/medias/1765121369647-877860065.png",
    "originalname": "photo.png",
    "size": 1024000
  }
}
```

## Проверка доступа

Все файлы загружаются с правами `public-read`, что делает их доступными по прямой ссылке:

```
https://etosema.s3.regru.cloud/medias/filename.png
```

## Troubleshooting

### Файлы не загружаются

Проверьте:
1. Правильность S3 credentials в `.env`
2. Доступность endpoint: `https://s3.regru.cloud`
3. Права доступа к бакету `etosema`

### Старые файлы не отображаются

Запустите миграцию:
```bash
npm run migrate:s3
```

### Ошибки CORS

Убедитесь, что в настройках S3 бакета разрешены CORS для вашего домена.
